# الاختبارات

```bash
python tests/run.py            # كل الاختبارات
python tests/run.py numbers    # ما يطابق الاسم فقط
python tests/test_exams.py     # ملف واحد مباشرة
```

لا تحتاج إعدادًا: كل ملف يُشغّل التطبيق على قاعدة بيانات SQLite مؤقتة خاصة به،
فلا يمسّ أي بيانات حقيقية. المتطلبات هي متطلبات المشروع نفسها (`requirements.txt`).

## التشغيل على PostgreSQL

الإنتاج يعمل على PostgreSQL لا SQLite، والفروق بينهما حقيقية (القيود، الأنواع،
`ALTER TABLE`). لتشغيل الحزم نفسها على Postgres:

```bash
TEST_PG_URL="postgresql://postgres@127.0.0.1:5433/manarah" python tests/run.py
```

كل ملف يُنشئ **مخطّطًا (schema) خاصًا به** على الخادم، فلا تتصادم الحزم ولا تلمس
أي بيانات قائمة. لا تُشغّلها على قاعدة بيانات الإنتاج.

| الملف | ما يغطّيه |
|---|---|
| `test_exams.py` | بناء الاختبار، التشغيل والجدولة، حلّ الطالب والتصحيح الآلي، المراجعة اليدوية، التشغيل للغائبين، إعادة ترحيل الدرجات، عزل المعلّمين |
| `test_upload.py` | رفع كشف الطلبة وورقة الأسئلة: كشف الأعمدة، المعاينة قبل الحفظ، كل صيغ الإجابة الصحيحة، القوالب، والحمايات |
| `test_grading.py` | تقييم الطلبة بأسمائهم، الدرجة الموحّدة للأنشطة، مسح الدرجة، الدرجات خارج النطاق، وأدوات الاختبار الإلكتروني |
| `test_numbers.py` | رقم الطالب ودخوله به، رفع الدرجات مطابَقةً بالأرقام، نتائج الطالب، وفتح الاختبار لطلبة محدّدين |
| `test_concurrency.py` | ٣٢ طالبًا يسلّمون في اللحظة نفسها — لا تسليم ضائع ولا صف مكرّر |

`_harness.py` يحوي ما تشترك فيه الملفات (تهيئة التطبيق، تسجيل معلّم، بناء صف، رفع ملف).
